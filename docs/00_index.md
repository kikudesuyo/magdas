## プロジェクトについて

本プロジェクトは、**九州大学国際宇宙惑星環境研究センター (ICSWSE)** によって提供される、MAGDAS (Magnetic Data Acquisition System) データの解析・可視化を行う Web アプリケーションです。
EE-index の計算、取得、およびプロットを主な機能としています。
